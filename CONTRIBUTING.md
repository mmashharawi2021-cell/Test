# Contributing

1. Create a focused branch.
2. Keep examples small, reproducible, and tied to a chapter or lab.
3. Add or update tests for executable code.
4. Do not commit secrets, credentials, real personal data, or proprietary datasets.
5. Do not paste third-party code unless its license permits redistribution and the required attribution is included.
6. Prefer official standards and upstream documentation as references.
7. Run the CI checks before opening a pull request.

## Code classification
Every book code block should map to one of:
- **Runnable example** — expected to execute against the documented environment.
- **Illustrative snippet** — intentionally partial; must be labelled as such in the book.
- **Pseudocode** — conceptual only; never presented as directly executable.
