# Official repositories and normative references

Use these as source-of-truth references in the book and companion repository. Prefer standards/documentation over blogs.

## Core database and spatial stack
- PostgreSQL documentation: https://www.postgresql.org/docs/
- PostGIS official source page: https://postgis.net/development/source_code/
- PostGIS GitHub mirror: https://github.com/postgis/postgis
- Docker PostGIS image repository: https://github.com/postgis/docker-postgis
- PROJ: https://github.com/OSGeo/PROJ
- pyproj: https://github.com/pyproj4/pyproj
- GDAL: https://github.com/OSGeo/gdal
- GeoPandas: https://github.com/geopandas/geopandas
- Shapely: https://github.com/shapely/shapely

## API and web mapping
- FastAPI: https://github.com/fastapi/fastapi
- Psycopg 3: https://github.com/psycopg/psycopg
- MapLibre GL JS: https://github.com/maplibre/maplibre-gl-js
- MapLibre Style Specification: https://github.com/maplibre/maplibre-style-spec
- OpenAPI Specification: https://github.com/OAI/OpenAPI-Specification

## Geospatial standards
- OGC API - Features: https://www.ogc.org/standards/ogcapi-features/
- OGC API - Features repository: https://github.com/opengeospatial/ogcapi-features
- OGC API - Common: https://www.ogc.org/standards/ogcapi-common/
- OGC Web API Guidelines: https://github.com/opengeospatial/OGC-Web-API-Guidelines
- GeoJSON RFC 7946: https://www.rfc-editor.org/rfc/rfc7946
- HTTP Semantics RFC 9110: https://www.rfc-editor.org/rfc/rfc9110
- STAC specification: https://github.com/radiantearth/stac-spec
- STAC API specification: https://github.com/radiantearth/stac-api-spec

## Security
- OWASP API Security Top 10: https://owasp.org/API-Security/

## Citation practice
For the printed book, cite a stable standard/version or a release/tag where possible. For fast-moving library documentation, cite the project and record an access date or the repository tag used by the companion release.
