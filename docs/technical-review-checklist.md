# Technical Review Checklist

- [ ] أمثلة CRS والوحدات صحيحة.
- [ ] كل SQL تعمل على schema الحالية.
- [ ] OpenAPI تطابق السلوك الفعلي.
- [ ] لا أسرار أو بيانات شخصية داخل الحزمة.
- [ ] Dataset كلها اصطناعية وموسومة بذلك.
- [ ] الاختبارات تغطي invalid geometry والحدود والتعارض.
- [ ] مراجع الأدوات تعاد مراجعتها قبل الطباعة النهائية.
