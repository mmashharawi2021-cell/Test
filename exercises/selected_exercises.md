# تمارين مختارة

1. عدّل Query الـBBOX بحيث ترفض envelope أكبر من الحد الذي تحدده أنت، واشرح سبب الحد.
2. أضف حالة `conflict` إلى تجربة المزامنة واكتب اختبارًا يثبت عدم فقد تعديل الخادم.
3. اكتب Data Contract لحقل `review_status` وحقل `observed_at`.
4. قارن `geometry` و`geography` في استعلام مسافة واحد وسجل الفرق في الوحدات والأداء.
5. صمم KPI واحدًا وبيّن البسط والمقام والفترة ومصدر البيانات.
